# Binary hook acceptance status

Snapshot: 2026-10-18. This register uses exactly two statuses: **Tested and proven** or **Open**. Each status applies only to its explicitly named acceptance scope. A narrower passing check never silently completes a broader requirement.

The ten original mechanisms are rows 1-10. Rows 11-14 track added integrations and provenance; row 15 is the newly proven causal sub-check of preparation/file gating. These are outcomes, not a claim that each row is a separate installed script.

For every **Open** entry in ordinary ChatGPT or hosted Cowork, the common reason is **R0**: this kit has no verified executable interception on that host for that outcome. Manual reads, written preferences, saved settings and local-host replays do not substitute for native host evidence. No row claims universal future behavior.
